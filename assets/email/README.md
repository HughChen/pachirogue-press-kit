# Email-only assets

Smaller copies used by the creator outreach emails (`0_content_creators` in the game repo).
The press kit page and downloads use the originals in `assets/images/` and `PressKit_PachiRogue/`;
nothing on the site links here, so these can be re-encoded freely.

| File | Source | Notes |
|---|---|---|
| `polaroid.gif` | `assets/images/outreach_polaroid.gif` | 680px wide, 10 fps (40 of 60 frames), ~1 MB |
| `cardboard_board.jpg` | photo of the physical cardboard board | 960px wide (shown at 480px), ~215 KB |

**Don't delete or rename these (or `assets/images/outreach_polaroid.gif`).** Sent emails don't carry
copies of their images; they link here and load the file every time someone opens them. Earlier
outreach emails link to `assets/images/outreach_polaroid.gif`; newer ones link to the files in this folder.
Re-encoding a file in place (same name) is fine, and every past email will show the new version.
